# Tommy Zaffalon — Portfolio

Personal portfolio website of **Tommy Zaffalon**.

🌐 Live: https://www.tommyzaffa.com

## Run locally

This is a static website — no build step needed.

```bash
# from this folder
python3 -m http.server 8080
# then open http://localhost:8080
```

Or just open `index.html` in your browser.

## Structure

- `index.html` — main page
- `js/` — page scripts · `images/` — images
- `CNAME` — custom domain for GitHub Pages

## Tech

Plain HTML, CSS and JavaScript, hosted on GitHub Pages.
